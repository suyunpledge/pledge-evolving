# Forge UI 交互优化 · 2026-10-03

本轮在现有 Tk 桌面端与真实 Forge 能力范围内修改，没有新增模拟对话或模型上下文。
主图标与已有图标、表情资源保持原有机制。

## 设计调整与原因

| 目标 | 实现 |
| --- | --- |
| 降低初次使用时的判断负担 | 欢迎页明确区分对话、执行任务与浏览工作区；三个入口直达已有操作，宽窗口横向排列，窄区域纵向排列。短窗口隐藏装饰画，为操作留出空间。 |
| 减少目录对注意力的占用 | 智能体目录默认折叠，显示真实数量；展开后在有高度限制的区域内滚动，完整列出已有目录。最近对话和底部设置始终有空间。 |
| 让主要操作更容易找到 | 新建对话使用低饱和主色，当前导航有独立选中底色；导航增大热区，发送和停止按钮增至 36 像素。模型选择集中在输入卡内。顶栏可随时展开侧边栏。 |
| 减少阅读疲劳 | 增强必要说明、占位文字的对比度；绿色用户气泡变为较深的绿色，并匹配绿色边框，保留角色区分。白色用户正文与绿色背景的对比度为 6.34:1，输入提示为 5.58:1。 |
| 用文字反馈状态，降低记忆负担 | Agents 保存入口固定在视图底部，就近显示未保存、已保存与保存失败；失败保留修改。用“参与”“提示词”“独立上下文”“共享近期对话”替换含糊缩写与内部枚举。 |
| 防止配置模式歧义 | 用户启用集群或分工时，另一个模式关闭；说明额外模型调用。仅显示选择的方案数，对已有配置的加载和运行优先级保持兼容。保存后才影响下一轮对话。 |
| 减少重复操作与误触 | 空输入不能发送；停止请求提交后按钮暂时停用并显示正在停止，避免重复请求。生成期间仍可准备下一条草稿。 |
| 改善键盘操作 | 自绘按钮、导航、欢迎入口支持 Tab 聚焦与回车/空格激活，并显示焦点。命令菜单支持方向键；模型选择器支持从搜索框进入结果、方向键选择、回车确认。 |
| 减少提示遮挡与生命周期问题 | 工具提示延迟 450 毫秒出现，限制宽度和屏幕位置；离开、点击和销毁控件时清理提示及计时器。 |

## 修复的布局与交互问题

- 最近对话的可扩展 Canvas 先占满侧栏，会把设置/关于/收起入口挤出窗口：固定入口先预留空间。
- 欢迎画面过高，第三个入口被输入区域截断：缩小装饰画，按可用高度隐藏装饰，重排操作卡片。
- 搜索框失焦时重建模型列表，销毁刚取得焦点的结果：失焦只更新提示，内容改变才重建列表。
- 空白会话的不同进入路径显示不同入口：统一新建和清空后的欢迎操作。

- `python run_offline_checks.py`：142 项桌面回归测试，包含 8 项新增真实 Tk 交互测试。
- 对比度、空输入与键盘发送、停止去重/保留草稿、菜单方向键、模型键盘选择、提示销毁、目录展开后的固定入口、保存失败反馈与窄窗口欢迎入口均有验证。
- 实际源程序截图检查：1360×850 主界面、最小窗口 940×700、1000×720 Agents 面板；使用临时用户配置和空会话，关闭自动联网启动。
- Python 编译检查与 Git 空白检查。
- 单文件桌面程序重新构建并进行启动冒烟测试。

这些是代码与布局验证，并非真实用户的受控可用性实验。原有模型/网络响应时间和 Tk 对部分组合 emoji 的显示限制仍由原有实现决定。

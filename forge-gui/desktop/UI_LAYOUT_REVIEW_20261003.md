# Forge GUI 布局复审 · 2026-10-03

源码根目录：`C:\Users\匡溯昀\pledge-evolving`。GUI：`forge-gui/forge_gui_v2.py`。

## 本轮修改

1. **文字和 Emoji**：气泡内部 Canvas 窗口宽度受实际容器约束。正文可用宽度扣除真实内边距；头像区域先在父布局中占位，剩余宽度再传给正文。图片按当前字体行高选择尺寸；文本高度根据 Tk 实际绘制像素计算。去掉 Emoji 周围人为插入的零宽字符，复制恢复原始 Unicode。普通标题和路径按分配宽度换行。
2. **消息层级**：头像、名称、时间独立成头部；短回复正文贴合内容，长正文限制阅读行宽；工具和动作置于正文之后。工作区操作改为带文件夹图标的紧凑按钮。动作组在空间不足时换行。
3. **输入区**：正文编辑、附件/上下文/命令、Provider/Model/模式/发送三层。模型过长显示省略号，真实模型值保持完整。模型状态在窄窗口换行，发送和停止保留独立位置。长草稿根据可用高度限制编辑行数，其余内容通过编辑框内部滚动访问。
4. **侧栏**：明确“功能导航”和“历史记录”，使用分隔线、间距及不同背景。小窗口自动收起侧栏，保留展开入口。
5. **工作区**：代码、Diff、预览初始比例改为 45:35:20。分隔线可以拖动；窗口缩放保留用户选定比例，刷新不会恢复默认比例。Diff 空态说明真实 Git 状态，并提供浏览更改或打开文件入口。切换仓库重置 Diff 选择状态。
6. **空态和短对话提示**：显示真实选择的仓库及实际 Git 改动数量。建议只填入草稿，确认后才发送；保留已有草稿。提示在长对话或空间不足时隐藏，不写入聊天历史或模型上下文。
7. **代码块访问**：长代码行提供水平滚动；超过 24 行的代码块提供垂直滚动。

保留现有框架、模型调用和功能开关，不引入新的 GUI 依赖。

## 验证方式

`python run_offline_checks.py`：使用临时目录和隔离凭据运行桌面回归，不发送付费模型请求。

新增 `test_layout_dpi.py`：

- 100% / 125% / 150% / 175% / 200% 的 Tk 字体缩放；确认字体度量确实发生变化。
- 1920×1080、2560×1600、960×900、1280×800、最小 940×700，共 25 种组合。
- 检查编辑、附件、模型、模式、Provider、发送和停止的实际边界。
- 遍历正文文字/Emoji 的绘制框，并检查沿途父容器是否裁切；缩放窗口和展开工作区后重复验证。
- 拖动原生分隔线后刷新及调整窗口高度；验证用户比例保留。
- 检查真实临时 Git 仓库的改动数量、建议草稿不会进入历史、长对话隐藏提示。
- 检查最小窗口的长草稿、代码块滚动、Diff 空态到真实文件的转换。

此测试改变 Tk 缩放及窗口分配尺寸，不修改用户 Windows 显示设置。Windows 系统缩放切换、跨显示器移动和不同显示器 DPI 仍需实际环境验证。

预览在隔离状态中生成。任何写有“界面回归测试”的对话都仅存在于临时测试窗口，未写入用户聊天历史。

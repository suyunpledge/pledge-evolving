## 人机工程调整

- 保留输入区和状态反馈的空间；窄窗口收起重复的顶部导航，左栏仍可访问所有页面。
- 多行输入、明确的键盘提示；生成时发送位置切换为停止，防止重复请求。
- 任务策略与运行按钮分行，主要操作保持可达。
- 用户在发送前能看到精确的消息角色与附件内容，并能关闭历史或移除附件。
- 仓库变更列表把文件名和行数统计分行，便于识别文件。
- 当前不支持的语音、分栏 Diff 占位入口移除；其他尚未接入的导航维持明确的说明页。

## 能力边界

- GUI 对话使用现有 OpenAI 文本/SSE 接口；其他 Provider 协议通过 Forge 任务使用。文本附件不等于图片识别。
- Forge CLI 在执行结束后返回步骤，因此不展示捏造的实时工具进度或耗时。
- 停止生成会立即更新界面；若网络正在等待数据，连接返回或超时后才完全结束，期间禁止并发发送。
- 工作区代码与终端日志只读。大型文本预览限制 400 KiB，目录树最多 2000 个节点；大型仓库 Git 刷新仍可能短暂等待。

审查基线：`6a9e6b4`，2026-10-05。修改仅涉及源码、测试和本报告。

## 已确认的问题与修复

| 场景 | 原行为与风险 | 修复 | 回归验证 |
| --- | --- | --- | --- |
| 大插件目录 | 后台读取完成后，Tk 回调一次创建全部卡片；500 条测试目录产生 500 次创建，阻塞输入派发 | 每页最多 12 张卡片，每张之间让出事件循环；工具每页最多 40 条，所有条目可通过翻页或搜索访问 | 大目录创建上限、1000 条真实 Tk 卡片、100% / 200% DPI、最小窗口、末页可达 |
| Windows 页面布局/输入法定位 | Configure/Focus 回调强制 `update_idletasks()`，嵌套进入整个窗口的布局队列；30 次布局事件会触发 30 次全局刷新 | 定位延后到 idle，一批事件合并一次；控件销毁取消待处理回调；保留普通字符键不重置定位的语音输入修复 | 回调合并、禁止嵌套事件循环、现有聊天/输入/DPI 测试 |
| 流式回复自动滚动 | 每段输出也强制刷新全局布局，放大消息绘制成本 | 合并到下一帧滚动；手动滚轮取消待自动滚动 | 合并请求、实际滚到底部、手动滚动取消 |
| 搜索和筛选 | 每个字符重读磁盘、权限状态与网关，完成后重建全部卡片 | 120ms 合并筛选，复用已读取的快照；进入页面、刷新和插件操作仍读取真实状态 | 连续搜索不提交后台扫描，筛选匹配最终关键词 |
| 快速返回再进入 | 每次进入都排队扫描，语言/页面连续切换会持续产生后台工作 | 两秒内复用最近快照，过期后重新读取；刷新和插件操作直接触发真实读取 | 连续进入不扫描，过期后重新扫描 |
| 首次远程同步 | 读取本地目录之前先等待远程源；旧测试用 `unittest` 分支避开生产同步路径 | 本地/缓存快照先返回，自动和手动同步走同一受控后台任务，完成后重新读取 | 慢同步期间缓存卡片可见、可以返回、同步不能重复提交；离线运行器明确模拟网络失败 |
| 返回/切到功能开关 | 已排队的绘制或筛选可能在隐藏页面继续工作 | 取消绘制和筛选；迟到的读取结果只更新快照；重新进入从快照恢复 | 返回后不再创建卡片、原导航父容器及布局恢复测试 |
| 插件加载错误 | 每个失败插件都向状态区排队，形成大量状态切换 | 一批失败只发布一条摘要，卡片保留各插件的执行状态 | 现有运行时/故障隔离测试 |
| 远程同步或异步绘制失败 | 新异步路径需要释放 busy 标志，避免永久阻止重试 | 同步失败释放 busy；卡片/工具绘制失败显示失败状态 | 慢同步收尾、失败状态与现有生命周期回归 |
| 语言偏好保存与后台读取并发 | Windows 文件读取未关闭时，原子替换可能失败；完整语言测试曾出现保存返回 False | 进程内配置读取与读改写使用同一可重入锁；锁内只进行本地配置 I/O | 先写模拟 Windows 删除共享冲突的失败测试，再验证写入等待读取结束且保存成功 |

另外修正了外部生态源开关忽略保存失败，以及统计文本直接格式化翻译标记导致参数未展开的问题。

## 范围与限制

- 未重构插件注册、Policy、权限授权、信任或执行边界；分页不会改变实际注册的工具集合。
- 目录快照仅用于展示。插件执行仍进行运行时授权和当前文件状态检查。
- 网络超时仍是现有 HTTP 超时语义，本轮没有把第三方执行描述为系统沙箱，也没有承诺所有网络读取都有严格总时限。
- 公共网站冒烟需 `FORGE_NET_TESTS=1` 显式启用；离线验收使用临时状态与模拟网络，不依赖公共站点。
- 目前桌面打开的是 `forge-desktop` 可执行程序。源码修复不会自动进入旧 EXE；本轮按既有约束不打包、不替换运行中的程序。

# Forge UI 审查与优化（2026-10-05）

基于 `1ff7e31` 的当前源码，保留暖灰 / Indigo 主题、品牌图标、插件权限语义和分批渲染机制。修改范围为桌面端源码、回归测试和本文档；未打包或生成 EXE。

## 发现与修复

| 场景 | 原问题 | 本次修复 | 回归验证 |
| --- | --- | --- | --- |
| 长插件名、作者、网址、权限和错误说明 | 名称和元信息挤在同一行；部分内容不换行，或使用固定 760px 宽度 | 名称、版本、分类与正文分层；按控件实际分配宽度扣除自身边距换行 | `test_ui_polish` 的五档缩放 × 十种语言卡片测试 |
| 插件生命周期状态和操作 | 状态徽章、知悉 / 启用 / 卸载 / 授权按钮固定在一行 | 使用现有 `flow_controls` 按实际宽度换行，保持组件 parent 和顺序 | 同一卡片测试检查控件完整宽度、高度和水平边界 |
| 工具列表 | 长工具名挤掉说明，工具桥错误和空状态可能溢出 | 名称、说明使用分配比例的两列并动态换行；错误及空状态跟随容器宽度 | 长名称和说明测试 |
| 工具调用与执行步骤 | 标题、正文不可靠地换行；耗时和完成状态被正文挤掉 | 先预留状态栏，再分配正文宽度；工具名、说明分层显示 | 长 trace 内容及耗时可见性测试 |
| 工具详情悬停 | 调整文本容器层级时可能丢失子标签上的提示 | 名称、说明及行容器均保留详情提示 | 真实 Enter / Leave 与延迟提示窗口测试 |
| 折叠卡片 | 只能鼠标展开；预先展开的卡片仍显示向右箭头 | 支持 Tab 聚焦、Enter / Space 切换及可见焦点；初始箭头跟随状态 | 键盘及箭头状态测试 |
| 聊天区域滚轮 | Enter 使用 `bind_all` 覆盖全局绑定，Leave 用 `unbind_all` 删除别人的绑定 | 按所在顶层窗口添加独立绑定，判断事件所属区域；销毁只移除自身回调 | 原有绑定保留、销毁清理测试 |
| 鼠标位于市场 / 设置 / 智能体 / 功能开关的子控件 | 只绑定 Canvas，指针在文字或按钮上时不能可靠滚动 | 复用相同的区域滚动处理 | 子控件滚动、页面导航及设置交互回归 |
| 原生编辑器、相邻或嵌套滚动区 | 全局滚动会带动错误容器 | 可滚动 Text / Listbox / Scrollbar 保持原生行为；只滚动最近的 Canvas 区域 | 内嵌编辑器、相邻区域、只读正文、嵌套 Canvas 测试 |
| 页面切换 / 替换正文时销毁 Markdown 容器 | 新分批渲染链没有保存并取消 after token；销毁 Tk 回调后仍留定时任务，后续出现 `invalid command name` | 保存单个待执行 token；容器 Destroy 时取消，只在实际完成后触发 on_done | 中断进行中的渲染并验证 token 移除、不会错误报告完成；渲染等价性及响应性回归 |
| 快速切换历史 / 新建对话 | 旧历史分批加载链继续往当前页面添加消息；销毁页面仍留根窗口 after 回调 | 跟踪单个加载 token、渲染代次和会话 ID；替换加载、新建对话、销毁聊天区域及关闭窗口均取消任务 | 快速切换不串消息、销毁移除 token、新建空白会话不混入旧内容 |

工程心理学上的目标：将名称、状态、内容和操作分层；让按钮始终可识别和到达；保留耗时 / 完成反馈；鼠标和键盘行为一致；长文本完整显示而不以裁切隐藏权限或错误信息。

## 验证范围

- 先运行新增测试复现失败，再做最小修复。包括窄容器、长字符串、100% / 125% / 150% / 175% / 200% Tk 字体 / DPI 缩放和十种界面语言；测试确认字体度量确实变化。
- 原有回归覆盖主输入区、消息 Emoji、欢迎页、文件 / Diff 工作区、功能开关、设置、模型选择、输入法、分页和市场响应性，以及返回页面后 sidebar 的 parent / order / dock 不变。
- 使用 computer-use 查看正在运行的桌面客户端；另启动临时隔离的源码预览，在真实窗口验证市场展示和“返回对话”。预览只读取随源码分发的内置目录，不连接模型 / 网关、不载入或修改真实对话，验证后已关闭。
- 缩放回归是独立 Tk 解释器中的布局 / 字体模拟，没有修改 Windows 显示设置。真实 Windows 系统级切换 DPI、输入法与多显示器迁移不等同于这些测试。

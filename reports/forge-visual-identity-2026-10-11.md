# Forge 视觉形象优化 · 2026-10-11

本轮由 GPT-6 Luna 完成静态品牌图形、GPT-5.6 Terra 完成功能图标与反馈，主 Agent 负责统一色彩、关键控件、审查和验收。目标是加强已有界面的辨识度；导航组件树、功能入口顺序与对话排版维持原契约。

## 视觉语言

| 角色 | 处理 |
| --- | --- |
| 背景与卡片 | 深墨蓝灰层级：背景 `#11131B`，内容面 `#202636`；减少大片同色灰的平面感 |
| 主要动作 | Indigo `#5955D9`，悬停 `#6962E3`，边缘带轻微静态光感 |
| 选中与聚焦 | 冷紫文字、细边框和焦点轮廓；保持选中态、hover 与键盘焦点可区分 |
| 品牌图形 | 欢迎区域采用切面火种、断开的轨道与分叉 Agent 节点，暖色仅作小面积点缀 |
| 功能图标 | 沿用统一矢量图标体系；小尺寸“更多”改实心三点，警告点与三角轮廓更清楚 |
| 反馈 | 图标按钮与发送按钮增加即时 hover / pressed / focus / disabled 表达，保留原点击和键盘激活时机 |
| 语义色 | 规划仍使用橙色、成功使用绿色；错误色提亮，确保文字在内容面上可读 |

主 logo 与厂商品牌标志沿用现有资产。欢迎 Canvas 固定 25 项图元，没有动画或 `after` 任务；按钮反馈由输入事件触发，没有新增轮询。

## 预览与实现

- [视觉样式预览](forge-visual-identity-preview.html) / [预览图片](forge-visual-identity-preview.png)。图形直接从当前 `decor.py` 与 `ui_icons.py` 绘制参数导出，色彩取当前 `gui_theme.C`。
- 预览页是设计样式检查产物，**不是运行中 Forge 窗口截图**，不含虚构对话或用户数据。
- 原生 computer-use 与浏览器工具初始化均返回 `failed to write kernel assets: 系统找不到指定的路径`。重置后再次初始化仍失败，因此没有声称完成原生窗口截图验收。静态预览通过本地无头 Chromium 渲染并目视检查。
- 生产修改位于 `gui_theme.py`、`decor.py`、`ui_icons.py`、`chat_widgets.py` 和 `forge_gui_v2.py`。

- 真实 Tk 检查发送按钮 hover、按下、释放、禁用时不触发动作，以及重复切换状态不累积 Canvas 图元。

# Forge 按钮反馈与色彩优化

基于 `f4bfe62` 的源码。本轮修改共享控件和少量入口的视觉状态；保持现有组件树、导航顺序、主图标和业务流程。

## 改动

| 部位 | 调整 |
| --- | --- |
| 主操作 | 保留 Indigo 常态，悬停提亮，按下使用更深的紫色；键盘焦点使用更清楚的冷紫轮廓 |
| 次级操作 | 悬停显示细边框和较亮的底色，按下显示更深的底色 |
| 停止 / 危险操作 | 保留红色文字，悬停和按下增加红色边框与深红背景 |
| 禁用状态 | 主按钮退出强调色，使用中性底色和图标，恢复普通光标，并退出 Tab 焦点遍历 |
| 输入区 | Agent 集群使用冷紫色细框，规划保留橙色；模型入口原有边框不再被键盘绑定覆盖 |
| 任务策略筛选 | 可通过 Tab 聚焦、Enter / Space 激活，悬停时保留选中状态的区别 |
| Gateway 按钮 | 接入同一套反馈，后台启动、停止和状态文字更新保留原有控制逻辑 |

## 代码修正

- `bind_keyboard_action` 保留已有的语义边框。
- `IconButton` 使用实际禁用状态选择图标颜色。更新文字、前景色或颜色参数别名时，不会使禁用图标恢复为可用状态。
- 视觉反馈与用户配置颜色分开保存；禁用期间更新颜色后，启用会恢复最新颜色。规划等显式边框也可跨文字更新和样式重应用保留。
- 保留原生鼠标释放激活、拖出取消、Space 激活和 `invoke()` 行为；新增 Return 激活。反馈使用局部事件和缓存，没有新增动画、轮询或全局事件绑定。
- 移除一次重复的按钮颜色设置；颜色参数别名使用共享映射。

生产源码：`forge-gui/gui_theme.py`、`ui_icons.py`、`chat_widgets.py`、`forge_gui_v2.py`。新增 `test_control_feedback.py` 的 11 项回归，并纳入默认离线入口。

- 覆盖文字和反馈色对比度、鼠标拖出取消、键盘激活、禁用与重新启用、样式绑定和计时器不累积、Emoji、模型切换后的输入焦点、导航恢复，以及五档 Tk 缩放和十种界面语言的控件边界。

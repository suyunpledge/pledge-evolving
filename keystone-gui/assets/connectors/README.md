# Connector icon sources

The icons identify the corresponding services. Brand marks belong to their owners.

- Full-color marks from [SVG Logos](https://github.com/gilbarbara/logos), as published in `@iconify-json/logos@1.2.11`.
- Monochrome product marks from [Simple Icons](https://github.com/simple-icons/simple-icons), as published in `@iconify-json/simple-icons@1.2.70`. The Keystone palette provides the fill colors.
- Google Contacts from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Google_Contacts_icon_(2022).svg).
- Exa and Firecrawl marks from their [Exa brand kit](https://exa.ai/brand) and [Firecrawl brand kit](https://www.firecrawl.dev/press-brand).
- Context7 from the [official MCP server manifest](https://github.com/upstash/context7/blob/master/server.json).
- Outlook Calendar uses a Keystone calendar glyph.

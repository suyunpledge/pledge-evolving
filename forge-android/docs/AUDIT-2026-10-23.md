## 尚未实现、不能宣称上线的部分

1. **Android arm64 PRoot/busybox 宿主二进制未提供**。只构建 Ubuntu rootfs 不能补出 Android bionic 可执行程序；还需追溯来源、依赖和真机执行验证。
2. 服务还没有把 tool_call 接到 DeviceTools.handle，也没有实际绑定 ShizukuGate/ForgeToolClient 与动态能力上报。当前桥默认不发布任何设备工具，避免虚报可用。
3. 操作确认 UI、完整取消/断线恢复、多个 WS 同会话连接的生命周期策略尚未完成；设备写操作保持拒绝。
4. PRoot 解包器仍需完善：中断解包的原子替换、旧镜像升级、进度线程、超时进程与输出管道清理。不能把 .forge-extracted 标记当成镜像版本验证。
5. Shizuku shell 的 readText 在 waitFor(timeout) 之前，超时并不能限制阻塞读取；screencap 使用临时文件，与协议“不落盘”表述不符。
6. Accessibility 树的节点预算/文本转义、截图回调超时后的资源回收，仍需在设备端补测；屏幕坐标还没有桌面端那样的观察身份、过期和旋转复核。
7. 当前只有对话页，Work/Code/Settings 页面、提供商配置/密钥设置页与本地模型推理未实现；“Compose 壳已编译”不代表能直接使用用户现有桌面模型配置。

## 构建环境说明

Windows JDK 17 `C:\jdk`、Android SDK `C:\sdk`，独立 Ubuntu noble WSL 分发版 `ForgeAndroidBuild`。
WSL 官网安装失败后使用 Ubuntu Base 导入；构建在 Linux `/root/forge-arm64-build`，不在 NTFS 上解包 rootfs。
WSL x86_64 用 QEMU/binfmt 完成 arm64 第二阶段；debootstrap 验证 Ubuntu Release 签名和包校验和。
仅本轮进程使用短 TEMP/TMP、代理与临时 Maven 镜像配置，未修改 Windows 全局网络配置或防火墙。
没有用假 tar、空镜像或任意同名二进制替代真实产物。
构建结束后已停止本轮的临时转发与专用 WSL 实例，保留分发版、缓存和构建目录供复现；没有终止 Docker 的 WSL 分发版。
